Vercel CEO Guillermo Rauch ported his Mini web browser to Rust and Swift: faster, more secure, and nicer to iterate on than Electron + Bun. He keeps Safari-like UX with Chromium via the cef crate, embeds an agent through fx acp talking to a local fx CLI over ACP, then manages the browser via an MCP server. Ditching Electron unlocked Liquid Glass, faster boots, and more Mac-native focus/input control. His bet: software will "nativify" faster than people expect, with Vercel's Fluid helping whether you choose Rust, Go, Zig, or scripts. Built with Opus 5.5 and Sol 6.

Vercel CEO Guillermo Rauch 把 Mini 浏览器移植到 Rust 与 Swift：比 Electron + Bun 更快、更安全，迭代体验也更好。他用 cef crate 捆绑最新 Chromium，保留接近 Safari 的体验，同时用 fx acp 通过 ACP 连本地 fx CLI 嵌入 agent，再经 MCP server 管浏览器。丢掉 Electron 后拿到 Liquid Glass、更快启动，以及更 Mac-native 的焦点与输入控制。他判断整个软件世界会比大家预期更快 “nativify”，而 Vercel 的 Fluid 会支持你选 Rust、Go、Zig 或脚本。这次用 Opus 5.5 与 Sol 6 做成。
