Separately he announces full read/write Box content interoperability with Claude via MCP in partnership with Anthropic, so agents can pull files into workflows and write updates back while viewing them inside Claude.

Box CEO Aaron Levie 认为 agent swarm 会再推一轮产出跃迁，并拉开采用者与未采用者的差距。演进路径：chat（更快但仍受交互速率限制）→ 能完成整项任务的 agent（把小时/天压缩成分钟）→ 目标导向的 swarm，在自包含数字环境里没有天然生产力上限（编程、交易、生命科学、IT 自动化、安全、数学、动画等）。另外他宣布与 Anthropic 合作，通过 MCP 给 Claude 打通 Box 内容的完整读写：agent 既能把文件拉进工作流，也能写回更新，并直接在 Claude 里查看。

Designing for Agents — Zeno Rocha, Resend

The Takeaway: When coding agents pick your infra, docs-and-machine-readable surfaces beat a decade of classic SEO: Resend won agent default status with FAQ/ask-answer pages, llms.txt, markdown docs, and product choices that assume agents are users, while still grinding deliverability down to the metal.

要点： 当 coding agent 替你选基础设施时，面向机器可读的文档表面比十年传统 SEO 更管用：Resend 靠 FAQ/问答页、llms.txt、markdown 文档，以及默认假设 agent 也是用户的产品选择，赢到了 agent 默认推荐位，同时仍在把投递做到“down to the metal”。

Resend CEO Zeno Rocha (feed title; host ASR also hears "Zino") joins Latent Space (channel URL in feed). He still gets recognized more for the Dracula theme than for email some days, came from front-end/HTML5 with no email background, and admits that if he had known how hard email is he might not have started the company. Metrics from the cold open: 4.3M users, 120k+ paid customers, ~$10M AR, NPM SDK downloads more than double SendGrid's, plus logos like Warner Brothers and HBO, and a Japanese group that brought ~20k domains across different registrars.

Resend CEO Zeno Rocha（feed 标题；主持人 ASR 也会听成 “Zino”）做客 Latent Space（feed 中的频道 URL）。有些日子人们仍更认他做的 Dracula 主题，而不是 email；他来自前端/HTML5，没有 email 背景，并承认如果早知道 email 有多难，可能根本不会开这家公司。开场数据：4.3M 用户、12 万+ 付费客户、约 $10M AR，NPM SDK 下载量已超过 SendGrid 两倍以上，客户包括 Warner Brothers、HBO，还有一个日本团队带来约 2 万个跨注册商域名。

The Swyx-shaped pain is literal in the transcript: even with Cloudflare email already configured, a model insisted "You must add Resend." Rocha's AEO answer is not a secret bribe at OpenAI/Anthropic. Twilio/Postmark/Mailgun had ten-plus years of SEO; Resend was behind in 2023, so they flooded docs and marketing with ask-and-answer FAQs on almost every page (including "Is Resend SOC 2 compliant?"), added llms.txt via Mentlfy (ASR spelling) on docs then marketing pages, and append .md markdown versions of pages. Product bets match the same thesis: auto-generate plain-text/markdown alongside HTML because "there are way more agents than before," which also helped spam filters and deliverability; MCP usage is growing faster than the CLI; careers can be applied to via CLI/API or by asking Claude to apply for a product designer role; inbound is expanding toward APIs for dozens/hundreds of agent-owned inboxes (read, unread, star, label).

转录里 Swyx 式的痛点是字面发生的：即便 Cloudflare email 已经配好，模型仍坚持 “You must add Resend.” Rocha 的 AEO 答案不是去收买 OpenAI/Anthropic。Twilio/Postmark/Mailgun 有十年以上 SEO；Resend 在 2023 还很落后，于是他们把文档和营销页铺满问答式 FAQ（包括 “Is Resend SOC 2 compliant?”），借助 Mentlfy（ASR 拼写）给文档再给营销页加上 llms.txt，并给页面提供追加 .md 的 markdown 版本。产品押注同一命题：因为 “agents 比以前多多了”，就自动从 HTML 生成 plain text/markdown，这也帮了垃圾过滤与投递；MCP 用量增速超过 CLI；招聘页可用 CLI/API 申请，或让 Claude 帮你申请 product designer；inbound 正往“几十/上百个 agent 邮箱 + read/unread/star/label API”推进。

Under the DX layer they started on SES; now they are building "down to the metal" for throughput and deliverability (IP pools, traffic control), with an announcement coming. Support policy that scaled knowledge: you can only answer a ticket with a link, so you write the docs first. Family constraint is explicit too: he would rather stay a $10M AR company close to his daughter than become a $100M company she does not want to play with.

在 DX 层之下他们起步用 SES；现在为了吞吐和投递正在 “down to the metal” 自建（IP 池、流量控制），并预告即将宣布。支撑知识沉淀的支持政策：工单只能用链接回复，所以要先把文档写出来。家庭约束也很明确：他宁愿做一家能陪女儿玩的 $10M AR 公司，也不想变成女儿不想靠近的 $100M 公司。
