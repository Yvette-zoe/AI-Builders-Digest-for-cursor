Training Data / A Model For Everyone: How Ronak From Trajectory Is Building Products For Continual Learning

The Takeaway: today's agents are stuck in "pseudo continual learning" (offline batch updates, AAA-map style); Trajectory's bet is democratizing train / eval / deploy in one loop so companies can climb toward Google-Maps-style online learning from real trajectories.

核心结论：今天的 agents 卡在 “pseudo continual learning”（离线大批量更新，像当年 AAA 纸质地图）；Trajectory 的赌注是把 train / eval / deploy 收成一个闭环，让公司能走向 Google Maps 式、从真实 trajectories 在线学习。

Ronak of Trajectory (host ASR also hears "Vernak"; co-founders: Michael from DeepMind / Gemini Robotics, ASR "Deepbind"; Arjun from Apple Vision Pro) frames continual learning against the human brain: we update online; agents mostly cannot. The AAA → MapQuest → Google Maps ladder is the product story: first give everyone MapQuest-like access to customize models without a research lab, then close the loop so every production trajectory updates the course. Architecture changes already show up in frontier models (he cites DeepSeek-style fast/slow memory and long skip connections); Trajectory wants to sit where product feedback becomes trainable signal.

Trajectory 的 Ronak（主持人 ASR 也听成 “Vernak”；联合创始人：来自 DeepMind / Gemini Robotics 的 Michael，ASR “Deepbind”；来自 Apple Vision Pro 的 Arjun）用人类大脑对照 continual learning：人在线更新，agents 大多不能。AAA → MapQuest → Google Maps 就是产品叙事：先让所有人不必养研究团队也能像 MapQuest 一样定制模型，再闭环到每条生产 trajectory 都能改航线。前沿模型架构已在变（他提到 DeepSeek 式 fast/slow memory 与跨层 skip connections）；Trajectory 想坐在“产品反馈变成可训练信号”的位置。

The released platform is a one-click train interface over agent traces plus "what good looks like," then eval and deploy in one place. Product philosophy is deliberately Apple-like: put training, eval, and deployment together until the loop feels magical. One customer story: train a model ~6x cheaper that moves open-source accuracy from about 4% to about 18%, then spend more tokens because inference is cheaper. Name choice: stop counting tokens as the unit of work; a trajectory (an RL rollout / economically valuable path) is the unit, and companies should own that path.

发布的平台是在 agent traces 与 “what good looks like” 之上的 one-click train，并在同一处 eval 与 deploy。产品哲学刻意像 Apple：把 training、eval、deployment 合在一起，直到闭环显得神奇。一个客户故事：训出约便宜 6 倍的模型，开源准确率从约 4% 拉到约 18%，再因为推理更便宜而敢花更多 tokens。取名用意：别再把 tokens 当工作单位；trajectory（RL rollout / 有经济价值的路径）才是单位，公司应拥有这条路径。

Primitives they want to shrink to: know what good looks like. In practice you still need production tracing (main agent, subagents, product events, user feedback). To label less, select ~100 representative traces from ~10,000, densely rubric them, then train a meta grader that propagates reward. Ideal UX: an observability view where you circle five strengths and five weaknesses and hit train. "I think by doing this of basically putting training, eval, and deployment in one place, making that just dead simple for every single person to do, And then you can close the loop and basically now upload that model back to production, gather new traces. It suddenly is this magical paradigm that I think every single company is going to adopt very soon." Longer bet: agents get recommender-system continual learning the way Google/Amazon/Facebook learned preferences online; start with easy model training, then self-improve harness and product until builders become gardeners. Optimistic end-state: specialize harness and model per workflow so enterprise AI adoption moves from ~1% toward 99%, bridging plentiful foundation-model intelligence with plentiful real-world experience.

他们想把原语缩到：知道 what good looks like。实践上仍要生产 tracing（主 agent、subagents、产品事件、用户反馈）。为了少标注，从约 10,000 条里挑约 100 条代表性 traces 做密集 rubric，再训 meta grader 把 reward 外推。理想 UX：在 observability 视图上圈出五个强项与五个弱项，然后点 train。“I think by doing this of basically putting training, eval, and deployment in one place, making that just dead simple for every single person to do, And then you can close the loop and basically now upload that model back to production, gather new traces. It suddenly is this magical paradigm that I think every single company is going to adopt very soon.” 更长赌注：agents 要得到 Google/Amazon/Facebook 那种在线学偏好的 recommender-system continual learning；先从易用的模型训练起步，再让 harness 与产品自我改进，直到 builder 变成园丁。乐观终点：按 workflow 特化 harness 与模型，把企业 AI 采用从约 1% 推到 99%，把 foundation model 的充足 intelligence 与真实世界的充足 experience 接上。
