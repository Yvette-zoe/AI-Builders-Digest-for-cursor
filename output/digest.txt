**Box CEO Aaron Levie** maps the on-the-ground security reality for large enterprises: a fragmented risk surface that only gets harder as libraries, tools, infra, data, and code sprawl. Most big companies can barely keep up, and smaller startups or non-tech firms are worse off. Data is often so fragmented that you cannot even see the true risk state; some systems over-privilege, others rely on security through obscurity. He says modernizing stacks first is what gives agent swarms a chance to help: fan out across security tools, test attack permutations, read logs, and score enterprise data for risk. That only became possible recently with long-running agents and good enough computer use, and he sees opportunity across identity, firewall, network, code scanning, and data protection, while still insisting the basics have to be fixed first.

Box CEO Aaron Levie 勾勒大型企业当下的安全现实：风险面高度碎片化，而要跟进的库、工具、基础设施、数据与代码只会越来越散。多数大公司已勉强跟不上，更小的创业公司或非科技公司更难。数据往往过于分散，以至于连真实风险状态都看不清；有的系统权限开得太宽，有的主要靠 security through obscurity。他说先把技术栈现代化，agent swarms 才有机会帮忙：横向铺开安全工具、测试攻击组合、读日志、评估企业数据风险。这只有在长跑 agent 与足够好的 computer use 出现后才真正可行；他看到 identity、firewall、network、code scanning、data protection 等整条安全栈的机会，但也强调一开始就必须把基础做对。
